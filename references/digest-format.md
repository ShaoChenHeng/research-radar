# 日报格式规范（冻结契约）

> 路径：`digest/YYYY/MM/YYYY-MM-DD/YYYY-MM-DD.md`（**以日期为名的文件夹**，PDF 也放在这里）
> **栏目、标题、条目 ID 前缀、分点标签一律以 `config.toml` 的 `[[sections]]` 为准。**

## 模板

```md
# 科研雷达 · YYYY-MM-DD（周X）

## <栏目1 标题>

### [<前缀>1] 条目标题
- **<分点1>**：……
- **<分点2>**：……
- **<分点3>**：[文字](URL)
- **标记**：

### [<前缀>2] 条目标题
- ……
- **标记**：

## <栏目2 标题>

### [<前缀>1] 条目标题
- ……
- **标记**：
```

## 硬性要求
1. 一级标题固定：`# 科研雷达 · <日期>（周X）`。
2. **每个栏目一个 `## 标题`**，顺序与 `config.toml` 的 `[[sections]]` 完全一致；标题**不带序号**。
3. **每条一个 `### [前缀N] 标题`**：`前缀` 取自该栏目的 `prefix`（如 `a` → `[a1]`, `[a2]`）。
4. 条目下**三个分点**，标签取该栏目的 `fields`（如 `["做了什么","结论","来源"]`）。
5. **链接分点必须是 Markdown 链接** `[文字](URL)`，不要裸 URL。
6. 条目之间**空一行**。
7. **条数**：`feed` 栏目落在 `min`–`max`；`queue` 栏目的条目由 runner 选出，**保持顺序与数量不变**。
8. 文件是 Markdown 正文，**不要**整体包在 ```代码块``` 里。
9. 内容须基于来源，**无法支撑就不写该条**，**禁止编造**。
10. **每条最后都有一行 `- **标记**：`**（默认留空）。可写多个（空格/逗号分隔）：`like`/`dislike`＝**反馈**；`save`＝**下载标记**；`learned`＝**已学会**（把对应课程条目归档）。由 `radar fb parse` 统一处理。
